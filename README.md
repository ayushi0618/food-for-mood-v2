# Food For Mood AI 🍜

Full-stack LLM application that analyzes user incidents with Gemini AI, suggests comfort food, and handles cart and orders in real-time with a sub-200ms latency target.

You can view the live deployment here: [Frontend App](https://food-for-mood-v2.vercel.app) | [Backend API](https://food-for-mood-v2.onrender.com)

---

## 🚀 Built With

* **JavaScript** (66.7%) - For server-side logic, API endpoints, and client functionality.
* **CSS** (27.2%) - For styling and responsive layouts.
* **HTML** (6.1%) - For markup structure.
* **React** - For the frontend user interface.
* **Node.js & Express** - For the backend server architecture.
* **MongoDB** - For persistent data storage (cart and orders).
* **Gemini API** - For intelligent emotional analysis and food recommendations.
* **WebSockets** - For real-time updates and notifications.
