# Food For Mood AI

AI-powered comfort food recommendation system.

## Features

- Gemini AI recommendations
- MongoDB storage
- React frontend
- Express backend
- Real-time notifications using WebSockets
- Cart and checkout system

## Tech Stack

React
Node.js
Express
MongoDB
Gemini API
WebSocket
